System Features & Capabilities

Explore the technical capabilities, architecture benefits, and user features built into our detection system.

Bidirectional LSTM Network

Uses dual-direction recurrent neural layers (`nn.LSTM`) to process text forward and backward, capturing subtle contextual dependencies and sensationalist phrasing.

Real-Time AJAX Inference

Submits news article text via asynchronous Fetch API calls to return prediction results instantly without requiring full browser page reloads.

Dynamic Confidence Gauge

Displays an animated visual confidence meter with glowing color indicators (emerald green for Real news, rose red for Fake news) alongside token count analytics.

User Authentication

Protected login and registration system powered by `Flask-Login` and `werkzeug.security` password hashing (`pbkdf2:sha256`) to ensure user data privacy.

Prediction History & Logs

Saves all past predictions into an SQLite database (`database.db`) with date filtering, average confidence metrics, and individual deletion controls.

Preset Sample Headlines

Includes one-click preset buttons for real science/financial articles and fake conspiracy news to allow instant system testing without manual typing.
